# BUG

**Dominando a arena com design inovador e estratégia inteligente.**

BUG é um robô de combate compacto desenvolvido para a XXI Disputa de Robôs da  
FIAP, com o propósito de aplicar engenharia eletrônica, programação embarcada e  
design estrutural em um ambiente real de competição.

---

### Sobre o Projeto

**Os interesses abordados no desenvolvimento do robô foram:**

• Comunicação via Bluetooth entre robô e smartphone  
• Controle de motores DC com Arduino  
• Desenvolvimento de mecanismo de ataque automatizado  
• Estruturação de hardware compacto dentro das regras da competição  
• Construção de site institucional para apresentação do projeto  

---

### Tecnologias Utilizadas

**Front-end**

• HTML  
• CSS  
• JavaScript  

**Hardware**

• Arduino  
• Motores DC 12V 300RPM  
• Módulo Bluetooth HC-05  
• Corrediça telescópica (arma)  

---

### Como Funciona

1. Usuário controla o robô via smartphone pelo módulo Bluetooth  
2. Arduino recebe os comandos e aciona os motores de locomoção  
3. Sensor detecta a aproximação do adversário e ativa a arma  
4. Corrediça telescópica se estende projetando a placa de EVA com alfinetes  
5. Arma retrai automaticamente em até 15 segundos conforme as regras  

---

### Objetivo

Aplicar na prática conceitos de eletrônica, programação embarcada e design estrutural  
— saindo do ambiente acadêmico para um ambiente real de competição, com regras,  
restrições de peso e prazo de entrega.

---

### Aprendizados Explorados

• Programação de microcontroladores com Arduino  
• Controle e integração de motores DC  
• Comunicação serial via Bluetooth  
• Projeto estrutural com MDF e restrições de peso  
• Desenvolvimento de site institucional com HTML e CSS puro
